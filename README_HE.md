# Down the Hill — בניית חבילת אוסטריה המלאה

**מה זה:** מאגר קוד מוכן להרצה אוטומטית ב־GitHub Actions. הוא אינו מכיל נתוני מזון שהומצאו או מאגרי מזון שהורדו מראש.

## מה GitHub יבנה

- `Austria-BLS-4.0.dthpack`: נתוני BLS 4.0 הרשמיים (מאגר גרמני, עד 7,140 מזונות) עם שמות בגרמנית ובאנגלית ושמות עבריים רק כשיש התאמה מילונית מבוססת.
- `Austria-OpenFoodFacts.dthpack`: עד 3,000 מוצרים שמסומנים כמשווקים באוסטריה ושיש להם קלוריות, חלבון, פחמימות ושומן ל־100 גרם או ל־100 מ״ל.
- `pack-index.json`: מונה רשומות, נפחים, רישיונות ובדיקת SHA256 של הקבצים.
- `ATTRIBUTION.md`: ייחוס ורישוי מקורות.

**כללי בטיחות:** כל מקור בחבילה נפרדת; אם אין די רשומות אמת, הבנייה נכשלת *ולא* מפרסמת חבילה לא שלמה. 72 כינויי מזון אוסטריים משמשים לחיפוש, לא כמקור נתונים תזונתיים.

## הפעלה בלי מחשב ובלי כרטיס אשראי

1. היכנס ל־[GitHub](https://github.com), צור חשבון Free (אם אין), ואז מאגר **Public** חדש, לדוגמה `down-the-hill-food-packs`.
2. העלה אליו את כל תוכן תיקיית המאגר הזו, כולל תיקיית `.github/workflows/`, תוך שמירה על מבנה התיקיות. אפשר דרך GitHub Desktop או ממשק העלאת הקבצים באתר.
3. פתח בכרטיסייה **Actions**, בחר **Build verified Austria Food Packs**, ואז **Run workflow**.
4. בסיום מוצלח: בכרטיסייה **Releases** תופיע מהדורה עם שני קבצי `.dthpack`. רק אם הכול עבר בדיקות תופיע מהדורה.
5. באייפון, שמור כל אחד משני קובצי `.dthpack` לאפליקציית **קבצים** (אפשר גם ל־iCloud Drive).
6. ב־Down the Hill Build 28 ואילך: **פרופיל ← חבילות מזון ← התקן או עדכן חבילה מקובץ**. התקן תחילה BLS ואז Open Food Facts.
7. בדוק חיפוש בגרמנית, באנגלית ובעברית; עבור למצב טיסה ובדוק שהמאגר עובד אופליין. לא כל מאכל מקומי יהיה בהכרח במקור BLS.

## אם משהו נכשל

- אם BLS לא הורד, ייתכן שהאתר הרשמי חסם קישור זמני או הורדה אוטומטית. אין לפרסם חבילה במקרה כזה. בדוק את הלוג של השלב `Download authentic BLS source`.
- אם OFF לא הורד, ייתכן שה־bulk dump אינו זמין זמנית או חורג מדיסק/זמן ריצה. יש להוריד את הקובץ הרשמי ולנסות שוב; אין לגרד אלפי מוצרים באמצעות API החיפוש.
- אם מספר הרשומות נמוך מ־6,000 עבור BLS או מ־3,000 עבור OFF, הבנייה תיכשל במכוון.
- אם יש שגיאת הרשאה ב־Release, במאגר: Settings → Actions → General → Workflow permissions → Read and write permissions (במידת הצורך).

## מגבלות

*לא נבדקה כאן הורדה אמיתית מהשרתים*, משום שסביבת יצירת הקבצים לא מאפשרת הורדת קבצי מקור. הבדיקות שבוצעו כאן הן על קבצי ניסיון סינתטיים לצורכי תקינות מבנה בלבד; קובצי ניסיון אלו אינם כלולים בחבילת ההפצה. יש לאמת את רשימת המזונות ותוצאות החיפוש לאחר הריצה ב־GitHub ובאייפון.

**BLS הוא מאגר גרמני**, לא רשמי אוסטרי. מאכלים אוסטריים שמותאמים בו מוצגים לפי המאכל האמיתי שנמצא. לא משתמשים ב־ÖNWT בלי רישוי מתאים.

## מה נשאר לפיתוח באפליקציה

Build 28 כבר יכול להתקין קובצי `.dthpack` ידנית. הורדה **מתוך האפליקציה בלחיצה אחת** טרם חוברה ל־GitHub Releases. לאחר שהחבילות יפורסמו, נוכל לחבר קובץ אינדקס HTTPS לעדכונים אוטומטיים, בלי להחליף את מנגנון המזונות הקיים.
